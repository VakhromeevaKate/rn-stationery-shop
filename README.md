# Аптека — каталог лекарств (React Native + Expo)

Учебный проект на основе `rn-stationery-shop`: каталог лекарств, поиск, фильтрация по категориям, карточка препарата, корзина и управление количеством через Zustand.

## Запуск

```bash
npm install
npx expo start
```

Откройте Expo Go на эмуляторе и выберите запущенный проект.

## Данные

`mocks/drugs.json` содержит 100 препаратов из предоставленного `db.json`. API-заглушка находится в `api/mockProductsAPI.ts`.

**Важно:** в исходном `db.json` нет цен, поэтому для демонстрации корзины генерируется условная цена в API-заглушке. Это не реальные аптечные цены. Приложение носит учебный характер; описание лекарств не заменяет консультацию врача.
